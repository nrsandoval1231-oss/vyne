# VYNE

**Your life in focus.** A privacy-first intelligent iPhone photo curator.

VYNE automatically organizes photos into overlapping smart albums, recommends safe cleanup of duplicates and clutter, and learns from keep/delete/skip decisions.

## Status
Product foundation and specifications committed. The iOS app is not yet runnable.

## Stack
Expo + React Native + TypeScript, Swift PhotoKit/Vision bridge, local SQLite, modular on-device intelligence.

## Safety
No silent deletion, no duplicated original photos, and no personal photo data or secrets in GitHub. iOS background organization is best-effort, with catch-up on launch.
